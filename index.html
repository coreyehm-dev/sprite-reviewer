Sprite Review

Choose the folder containing Source and Keep.
Pick your synced spritesorter folder to begin. Use Chrome or Edge on Windows or Mac.

Select a GIF to inspect its animation.

Drag this animation or a GIF card into ChatGPT's message box. This sends the original GIF file. If the drop is rejected, use Download GIF and attach it.

Arrow keys move between GIFs. K marks Keep, P marks Pass, U clears a choice. Your choices are written to review-decisions.json inside the chosen folder and sync with it. Copy kept GIFs places copies in Keep when you need files for production. Source GIFs and existing Keep files are never moved or deleted.
